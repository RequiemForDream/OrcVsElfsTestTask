Тестовое задание: мини-игра в жанре tower defense с механикой мерджа юнитов. Игрок отбивается лучницами от волны орков, покупает и объединяет юнитов, чтобы остановить босса до того, как враги дойдут до поля.

**Стек:** Unity, C#, Zenject, UniTask, DoTween

## Игровой процесс

- Поле 5×4, дорожка ведёт к нему справа — по ней движутся орки
- Лучница атакует врагов автоматически, орк погибает с 2 выстрелов
- За убийство орка выпадают монеты с анимацией полёта в UI
- Обучение: покупка второй лучницы → мердж двух лучниц в улучшенную
- Улучшенная лучница убивает орка с 1 выстрела (но дольше перезаряжается)
- После туториала — покупка юнитов за монеты (старт: 15, +5 за каждую покупку)
- Локация: 6–7 орков + босс (усиленный орк, урон 4-5 выстрелов улучшенной лучницы / 8-10 обычной)
- Если орки/босс доходят до поля — игрок проигрывает, персонажи умирают
- После победы над боссом или после поражения — каждый клик триггерит CTA (заглушка, событие в консоль)
